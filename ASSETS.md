# Assets

| Asset | Where it came from | Used in | Notes |
| --- | --- | --- | --- |
| Chrome, Cursor, VS Code icons | Copied from the apps installed on Will's Mac (`/Applications/*/Contents/Resources/*.icns`), resized to 128px WebP | Demos | Unmodified |
| Notes, Messages, Music, Reminders, Terminal icons | Copied from macOS 26 system apps (`/System/Applications`) | Demos | Unmodified |
| Slack, Notion, Claude, Codex, Obsidian, Safari tiles | Built by `scripts/make-icons.mjs` from each brand's official mark (via `@iconify-json/logos`) on a macOS-shaped tile; sources in `assets-src/` | Demos | Replace with the real app icon (128px WebP, same file name) when available |
| Archivo font | Google Fonts / Omnibus-Type, SIL Open Font License, via `@fontsource-variable/archivo`, subset to Latin | Everywhere | |
| Hopper mark | Placeholder (`Wordmark.astro`, `favicon.svg`) | Header, favicon, OG | **Replace with the final icon before launch** |
| `og.png`, `apple-touch-icon.png` | Generated by `npm run og` | Sharing | Regenerate after the icon changes |

Third-party app names and icons are used only to show which apps Hopper works with (nominative use); the footer says
so. Before launch, re-check each brand's guidelines (Apple's are the strictest) and swap any tile whose owner asks.
