If you use a window manager, your fingers already know it. That muscle memory is the main reason people don’t switch tools. So Hopper doesn’t ask you to drop it.

## Import your shortcuts in one go

Coming from **Rectangle**, **Magnet** or **Spectacle**? Open [Hopper’s window settings](/features/windows#presets), pick the app you used, and import its shortcuts. Left half is still left half.

Hopper tells you first if a shortcut is already in use. The one to know: Rectangle and Magnet put halves on <kbd>⌃</kbd><kbd>⌥</kbd><kbd>←</kbd> and <kbd>⌃</kbd><kbd>⌥</kbd><kbd>→</kbd>, which are Hopper’s [Back and Forward](/blog/back-button-for-your-whole-mac). You choose who gets them.

Out of the box, **no window shortcuts are set**. Nothing collides until you decide.

## 42 commands, one search box

Every window command is in search. Press <kbd>⌘</kbd><kbd>Space</kbd>, type “left half”, “center” or “next display”, press <kbd>↵</kbd>. Type “window” to see them all.

The set covers what you’d expect: halves, thirds, two thirds, fourths, quarters, sixths, maximize, almost maximize, a reasonable size, center, restore, move to an edge, fullscreen, and moving a window to the next display or desktop.

## Press it again

Run a half twice and the window cycles: ½, ⅔, ⅓. Or set it to carry on to your next display instead. Adjust the gap between windows from 0 to 128 points.

## Make the size you keep dragging to

Everyone has a size they drag to by hand. Make it a command: pick the size, pin it to one of nine anchors (a corner, an edge or the center) and nudge it. It shows up in search and can take a hotkey, like any built-in command.

## A whole setup on one key

A **layout** puts several apps where they go. It starts the ones that aren’t open, and can open a specific page or file first. Windows it doesn’t name stay where they are.

Say a “Deep Work” layout: Cursor on the left two thirds, Terminal on the right third. Give it <kbd>⌃</kbd><kbd>⌥</kbd><kbd>1</kbd> and your setup is one keystroke away.
